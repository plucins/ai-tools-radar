# AI Tools Radar

A full-stack web application for discovering and comparing AI developer tools. Browse a curated catalog of tools, select any two or more, and get a structured analysis generated by a local LLM — no API keys, no data sent to third parties.

## What It Does

The AI tooling landscape changes fast. Vendor marketing is noisy, and hands-on evaluation takes time. AI Tools Radar solves this by maintaining **evidence-based Markdown profiles** for each tool and enabling **on-demand structured comparisons** powered by a local LLM.

**Key features:**
- **Tool Catalog** — Browse AI developer tools by category (`cli/`, `ide/`, `agent/`, …)
- **Multi-Tool Comparison** — Select 2+ tools and get a structured LLM-generated breakdown
- **Local-First** — Comparisons run via [Ollama](https://ollama.com); nothing leaves your machine
- **Mock Mode** — Run and develop without Ollama installed (`LLM_MODE=mock`)
- **Markdown-Driven Data** — Add a tool by dropping a `.md` file; no backend code changes needed

## Running Locally

The frontend and backend are managed as separate packages. Open two terminal windows.

### 1. Backend

```bash
cd backend

# First run: copy the example env file
cp .env.example .env

# Install dependencies
npm install

# Start the dev server (with hot reload)
npm run start:dev
```

The API will be available at **http://localhost:3000**.

**Backend environment (`.env`):**

```env
NODE_ENV=development
PORT=3000
FRONTEND_ORIGIN=http://localhost:5173

# LLM settings
LLM_MODE=mock                         # Use 'ollama' for live comparisons
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama3                   # Any model pulled via `ollama pull`
OLLAMA_TIMEOUT_MS=120000
```

### 2. Frontend

```bash
cd frontend

# First run: copy the example env file
cp .env.example .env

# Install dependencies
npm install

# Start the dev server
npm run dev
```

The app will be available at **http://localhost:5173**.

**Frontend environment (`.env`):**

```env
VITE_API_BASE_URL=http://localhost:3000
```

## Using Live LLM Comparisons (Ollama)

To get real AI-generated comparisons instead of mock data:

1. [Install Ollama](https://ollama.com/download)
2. Pull a model:
   ```bash
   ollama pull llama3
   ```
3. In `backend/.env`, set:
   ```env
   LLM_MODE=ollama
   OLLAMA_MODEL=llama3
   ```
4. Restart the backend.

## API Endpoints

| Endpoint | Method | Description |
|---|---|---|
| `/health` | GET | Liveness check |
| `/tools` | GET | List all tools |
| `/tools/:id` | GET | Get a single tool profile |
| `/comparison` | POST | Generate a comparison (`{ toolIds: string[] }`) |

## Adding a New Tool

1. Create a Markdown file under `data/tools/<category>/<tool-name>.md`
2. Follow the evidence-based profile format used by existing profiles
3. Restart the backend (or rely on hot-reload)

No backend code changes are required.
